# Homeland

## Descrição

Este projeto desenvolve uma página web responsiva que apresenta as cidades natais de funcionários da TripleTen, aplicando práticas de HTML, CSS, BEM e design responsivo baseado no protótipo do Figma.
O foco é construir um layout adaptável para diferentes resoluções de tela (320px, 768px e 1280px), usando breakpoints estratégicos e técnicas modernas de layout.

## Funcionalidades

* Estrutura completa seguindo arquitetura de diretórios BEM.
* Configuração do `index.html`, folhas de estilo e conexão da fonte externa Inter.
* Layout adaptado para três larguras principais conforme o Figma.
* Design responsivo utilizando breakpoints em 544px e 1024px.
* Adaptação visual para resoluções intermediárias.
* Uso de flexbox, grid, object-fit e unidades relativas (% e fr).
* Otimização e compressão de imagens para melhor desempenho.

## Tecnologias Utilizadas

* HTML5
* CSS3 (Flexbox, Grid, Media Queries, BEM)
* Git e GitHub
* Figma
* Fonte Inter (versão Web)

## Objetivos de Aprendizado

* Aplicar boas práticas de organização de arquivos usando BEM.
* Desenvolver habilidades de design responsivo com breakpoints eficientes.
* Interpretar layouts do Figma e convertê-los em código.
* Aprimorar o domínio de HTML e CSS com foco em escalabilidade e consistência.
* Criar base sólida para projetos futuros que envolvam lógica e JavaScript.
